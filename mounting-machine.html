Automatic Mounting Press

ML-C

  • 몰드 사이즈25·32mm / 40·50mm
  • 작업 능력1회 1~2개 (스페이서 사용 시 2개)
  • 작업 온도0~250℃
  • 가열 출력1,600W(25·32) / 2,400W(40·50)
  • 장비 출력2,000W / 2,770W
  • 가열 시간최대 60분
  • 냉각 시간최대 30분
  • 메모리 모드40개 (가열온도·가열시간·냉각시간)
  • 장비 규격540 x 560 x 625mm
  • 장비 중량70~71kg

Automatic Vacuum Impregnation

MV01A

4.3인치 컬러 터치패널, 8개 메모리 모드, 한글 포함 다국어·단위변환을 지원합니다. 가스제거(Degassing) 사이클을 99개까지, 진공 파라미터(진공값·시간·압력)를 개별 설정할 수 있습니다. 기공 샘플의 기포 형성을 최소화하고 에폭시 디스펜서로 레진 충진이 용이하며, IC·전자재료·PCB 등 고온고압에 취약한 시료에 적합합니다.

  • 최대 진공값-600mmHg (-0.799bar / -79.993kPa / -11.602psi)
  • 진공펌프 출력300W
  • 펌프 유량86L/min
  • 진공챔버 규격300 x 330 x 300mm
  • 장비 규격540 x 550 x 560mm
  • 장비 중량45kg
  • 진공펌프 규격160 x 320 x 200mm
  • 진공펌프 중량9kg
